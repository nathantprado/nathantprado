# Hi, I'm Nathan Prado

I am a cloud infrastructure & automation engineer, developing solutions both for and using Microsoft's tech stack. I primarily focus on workflow automation and approach every project with the goal of reaching a zero-touch, fully automated end result that minimizes technical debt for IT teams. 

## What I Focus On
*   **Automation:** Writing PowerShell scripts and modules to eliminate recurring manual workflows and streamline administration.
*   **Infrastructure:** Architecting and managing Azure IaaS, Entra ID, and hybrid identity environments.
*   **Development:** Building desktop and web-based applications using C# and Blazor WebAssembly.
